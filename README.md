# そなえ帳（試作）

家にある防災備蓄を管理し、通信やインフラが止まっても使える防災アプリの試作です。

- 備蓄で「何日暮らせるか」を水・食料・トイレごとに表示
- 期限が近いものの表示と、「使った」から買い物リストへの自動追加
- 地震・停電・断水・通信障害・大雨の「最初にやること」と公式情報への導線
- データはすべて端末内に保存（サーバーには送りません）
- ホーム画面に追加すると、通信なしでも起動します（PWA）

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（画面と処理） |
| `sw.js` | オフラインで開くための仕組み（Service Worker） |
| `manifest.json` | ホーム画面に追加した時の名前・アイコン |
| `icon*.png`, `icon.svg` | アイコン |
